## Acceptance criteria



| Benchmark as | User reach |
| --- | --- |
| Strategy | High |

<Note>
    “Non-MFA” describes the account's existing sign-in policy. It does not make
    an email, SMS, or other additional verification step universally required.
    If the relying party's binding policy requires step-up verification, that
    verification must succeed before the new credential is accepted.
</Note>

| ID | Level | Acceptance criterion | How to verify |
| --- | --- | --- | --- |
| **W2.2-AC01** | Core | The creation offer is eligible only after successful conventional sign-in on a supported client when the account has no registered passkey. | Test an eligible account, an account with an existing passkey, an unauthenticated request, and an unsupported client. Only the eligible account receives the offer. |
| **W2.2-AC02** | Core | After an eligible sign-in, show a manual creation nudge that explains how a passkey improves the next sign-in, unless a passkey was already created by the automatic ceremony in W2.2-AC04. In the manual flow, the creation ceremony opens only after the user clicks Continue. | Complete an eligible sign-in. Confirm that the manual nudge explains the future sign-in benefit and that the manual flow opens one creation ceremony only after Continue is clicked. One automatic ceremony under W2.2-AC04 does not fail this criterion. |
| **W2.2-AC03** | Core | The created passkey is stored for the authenticated account and can complete a later passkey sign-in to that same account. | Complete creation, sign out and use the new passkey to sign in again. The assertion resolves to the same account. |
| **W2.2-AC04** | Quality | On suitable clients, open one passkey-creation ceremony automatically after the eligible sign-in. If it is cancelled or fails, show the manual creation nudge without an application error and wait for the user to click Continue before retrying. | Confirm that one ceremony opens automatically on a suitable client. Cancel or fail it, then confirm that the manual nudge appears without an error and no ceremony reopens until Continue is clicked. |
